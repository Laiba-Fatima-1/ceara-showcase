# Screenshots & demo video

This folder is intentionally empty in the showcase repo. Drop your own images here using the filenames below — the main `README.md` already links to these exact paths, so nothing else needs to change once the files exist.

| Filename | What to capture |
|---|---|
| `mode1-interview-screen.png` | Mode 1 live interview screen — camera feed, live transcription box, and signal monitor all visible |
| `mode1-report.png` | A finished Mode 1 candidate report — rubric score, signal bars, and at least one transcribed answer visible |
| `mode2-conversation.png` | Mode 2 Conversation Mode mid-chat — CEARA's message bubble and a candidate response both visible |
| `exhibition-photo.jpg` | A photo from the actual exhibition day — laptop, poster/standee, or the team presenting |

Recommended size: 1280×800 or larger, PNG for UI screenshots, JPG for photos. Keep file sizes under ~2 MB each so the repo stays lightweight.

For the demo video, you don't need to commit the video file itself — upload it to YouTube (unlisted is fine) or Google Drive and replace the placeholder line near the top of `README.md`:

```markdown
> 🎥 **Exhibition demo video** — [Watch the 3-minute walkthrough](your-link-here)
```
